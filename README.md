## 🛠️ Tecnologias Utilizadas

- **HTML5** estruturado e semântico
- **CSS3** moderno, responsivo (Mobile-First) e variáveis CSS
- **JavaScript (ES6+)** para interatividade e integração direta com API do WhatsApp
- **Arquitetura estática leve** (sem necessidade de backend ou banco de dados)

## 📸 Padrão Recomendado para as Imagens dos Produtos

Para garantir a melhor performance e harmonia visual na vitrine de 7 produtos:
- **Resolução recomendada:** 800 x 800 px (quadrada, proporção 1:1) ou 800 x 1000 px (vertical, 4:5)
- **Formato:** `.webp` (preferencial para web) ou `.jpg`/`.png` otimizados
- **Nomenclatura sugerida:** `modelo-01.jpg` a `modelo-07.jpg`
- **Fundo:** Fundo neutro, iluminação natural e foco nos bordados e detalhes artesanais
